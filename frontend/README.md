# Frontend de El Sol Dorado

Aplicación Angular del sistema académico del restaurante.

## Ejecutar

```bash
npm install
npm start
```

Disponible en `http://localhost:4200` y conectada por defecto al backend en `http://localhost:8080`.

## Validar

```bash
npm run build
npm test -- --watch=false
```

No copies `node_modules` entre Windows, Linux o macOS; vuelve a ejecutar `npm install` en cada equipo.
